Privacy policy

Last updated: 2026-09-29.

roma-vps-backup is a personal backup setup used only by its owner. It uses rclone with the Google Drive drive.file permission to create and access the backup files it creates in the owner's Drive. It does not request access to other Drive files.

AI Council discussion data is encrypted on the owner's private server before upload. Google Drive stores the encrypted backup files. The server stores OAuth credentials and encryption configuration to run scheduled backups. The owner keeps separate recovery information.

The setup does not sell user data, use it for advertising, or share discussion content with other users. Google and infrastructure providers process data to provide their services. Backups are kept until the owner deletes them. Revoking OAuth access stops future backups but may not delete backups already stored in Drive; the owner can remove those separately.

This policy will be updated if the backup setup or data handling changes.
